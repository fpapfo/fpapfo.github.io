# Donna Graham — FP&A

Personal site and portfolio for practical FP&A work, published with GitHub Pages
and built on Jekyll (Minima theme).

It covers three things:
- **Articles** — short, reproducible techniques for Excel, financial modelling,
  finance automation, SQL and Power BI, with the occasional longer deep-dive.
- **The Workshop** — workflows and decision tools documented as they evolve.
- **Decision Tools** — interactive tools you can open and use, not screenshots.

➡️ Live site: [https://dgrhm.com](https://dgrhm.com)
